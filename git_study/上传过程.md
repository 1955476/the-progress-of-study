1、先初始化当前目录为git仓库
```
git init
```
2、然后设置自己的用户名和邮箱(当前是全局配置)
```
git config --global user.name "your name"
git config --global user.email "your email"
```
还有另一种方式是设置当前仓库的用户名和邮箱(当前是本地配置)
```
git config user.name "your name"
git config user.email "your email"
```
解释:这里的username可以任意名称仅代表个人这次提交的用户名
3、绑定远程仓库(第一次需要绑定，后面每次提交时不需要绑定，但是要换仓库时需要重新绑定)
git remote add origin <remote-url> 
解释:这里的<remote-url>是远程仓库的url，例如:https://github.com/username/repository.git
同时这里的origin是远程仓库的名称，可以任意命名，但是建议使用origin,是后续向这个仓库提交代码时使用的名称
4、添加文件到暂存区
git add <file> | . | --all
解释:这里的<file>是文件名，可以是多个文件，也可以是所有文件(使用.表示所有文件)或所有子目录(使用--all表示所有文件和所有子目录)。
5、提交代码到本地仓库
git commit -m "commit message"
解释:这里的commit message是提交信息，建议使用英文，也可以使用中文
6、将本地提交到暂存区（将当前commit提交到origin仓库的branch-name分支上）
git push -u origin <branch-name>
解释:这里的<branch-name>是分支名称，建议使用main或master
7、将暂存区提交到远程仓库
git push origin <branch-name>
解释:这里的<branch-name>是分支名称，建议使用main或master

git push origin main --force
解释:这里的--force是强制提交，如果远程仓库有代码，会覆盖远程仓库的代码，建议在本地仓库有确认后使用
